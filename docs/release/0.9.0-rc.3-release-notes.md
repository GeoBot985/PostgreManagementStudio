# PostgreManagementStudio 0.9.0-rc.3

Release-candidate reliability update following Sprint 48 and Sprint 56
packaging and qualification hardening.

## Included

- Safer WPF startup, tab-switch, connection-state and shutdown error
  boundaries.
- Redacted and bounded user-facing messages for profile, file, export,
  clipboard, completion and result-page failures.
- Separate cancellation presentation and cleanup protection for connection and
  query-tab workflows.
- About-dialog version identity aligned with the informational release version.
- Release manifest support claim narrowed to the qualified PostgreSQL 18.4
  environment.
- Server activity, blocking/wait, lock diagnostics, and activity snapshot
  workflows are included; query-performance and database-statistics dashboards
  remain deferred.

## Qualification

- Release build: 0 warnings, 0 errors.
- Current solution baseline: 333 passed, 60 integration tests skipped without
  configured credentials, 0 failed.
- Package: self-contained Windows 11 x64 `win-x64` ZIP; SHA-256
  `22fa5b41a1952d90d5514d95efcc95b1b657169d378d6bf083f7ae4dc58b19ad`.
- Installer lifecycle: install, repair, user-state preservation, and
  uninstall passed in an isolated temporary profile.

## Scope

This remains an internal release candidate. Editable data, rich administration
workspaces, query/database statistics, settings/history workspaces, free
docking, multi-window operation, and several editor productivity features are
not part of the supported surface. See `RC_EXIT_REVIEW.md` for open release
gates.
