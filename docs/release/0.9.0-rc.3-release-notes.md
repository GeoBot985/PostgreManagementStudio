# PostgreManagementStudio 0.9.0-rc.3

Release-candidate reliability update following Sprint 48.

## Included

- Safer WPF startup, tab-switch, connection-state and shutdown error
  boundaries.
- Redacted and bounded user-facing messages for profile, file, export,
  clipboard, completion and result-page failures.
- Separate cancellation presentation and cleanup protection for connection and
  query-tab workflows.
- About-dialog version identity aligned with the informational release version.
- Release manifest support claim narrowed to the qualified PostgreSQL 18.4
  environment.

## Qualification

- Release build: 0 warnings, 0 errors.
- Isolated PostgreSQL 18.4 qualification: 3 iterations, 384 tests each,
  1,152 passed, 0 failed, 0 skipped, cleanup passed.
- Package: self-contained Windows 11 x64 `win-x64` ZIP.

## Scope

This remains an internal release candidate. Editable data, rich administration
workspaces, full monitoring dashboards, free docking, multi-window operation,
and several editor productivity features are not part of the supported surface.
