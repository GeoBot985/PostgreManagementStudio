# PostgreManagementStudio 0.9.0-rc.3 known issues and qualification gates

| Item | Severity | Release action |
|---|---|---|
| Remote TLS/password and client-certificate qualification is unavailable | High qualification gate | Qualify the exact advertised secure connection modes or remove them from the support claim. |
| PostgreSQL versions other than 18.4 are unverified | High qualification gate | Run the intended version matrix before broadening the manifest. |
| Clean-VM, Unicode-profile, locale and mixed-DPI campaign is incomplete | High qualification gate | Execute the documented Windows 11 standard-user matrix. |
| Candidate is unsigned and has no final malware/SmartScreen scan | High release gate | Sign the frozen artefact and scan the signed package. |
| Public licence approval remains pending | High release gate | Replace the licence placeholder and approve third-party notices. |
| Advanced workspaces and editable data are not supported | Product scope | Keep them unadvertised; use SQL editor and the documented compact workflows. |

No known issue is accepted for wrong-target execution, credential exposure,
unsaved SQL loss, transaction outcome misrepresentation, backup/restore target
confusion, installer data loss or ordinary-use crashes in the qualified local
environment.
