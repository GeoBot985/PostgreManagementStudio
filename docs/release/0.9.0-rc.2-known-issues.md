# PostgreManagementStudio 0.9.0-rc.2 known issues and qualification gates

| Item | Severity | Affected workflow | Workaround / release action | Data or security risk |
|---|---|---|---|---|
| PostgreSQL 14 qualification not yet executed | High qualification gate | Supported-version claim | Run the isolated RC suite against PostgreSQL 14 before public release | No known data loss; public support claim must remain withheld |
| Remote TLS and client-certificate qualification unavailable | High qualification gate | Secure remote connections | Qualify a dedicated TLS/password/certificate endpoint | No known leak; do not advertise the modes as qualified |
| Code signing and malware scan unavailable | High release gate | Public installation / SmartScreen | Sign after final artefact freeze and scan the signed package | User trust and distribution risk |
| Public licence decision and final third-party notices pending | High release gate | Public redistribution | Project owner must approve licence and attributions | Legal/distribution risk |
| Clean-VM, Unicode-profile, non-English, and mixed-DPI matrix not available | Medium qualification gate | Deployment/display compatibility | Execute the documented VM matrix | No known data loss/security risk |
| Data editing | Not supported | Editable grid workflows | Use SQL editor with safeguards | Not advertised; no edit operation is exposed |
| Service-only workspaces and advanced UI modes | Not supported | Feature discovery | Keep unadvertised until composed and qualified | No data/security risk |

No known issue is accepted for wrong-target execution, transaction outcome
misrepresentation, credential exposure, unsaved-work loss, backup/restore
wrong-target handling, or ordinary-use crashes.
