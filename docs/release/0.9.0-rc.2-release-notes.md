# PostgreManagementStudio 0.9.0-rc.2

Release candidate for internal qualification. It is a Windows x64,
self-contained desktop package for PostgreSQL query work and selected
administration tasks.

## Included release surface

- Traditional WPF desktop shell with File, Edit, View, Query, Database, Tools,
  Window, and Help menus.
- Query documents, opening/saving SQL, selected/full execution, cancellation,
  messages, result sets, bounded result display, copy, search, and export.
- Connection profiles with optional Windows Credential Manager references,
  environment classification, read-only enforcement, reconnect, and recovery.
- Object Explorer, metadata refresh, object search, query plan actions,
  import/export, backup/restore, maintenance, activity monitoring, and roles
  where the documented desktop workflow exposes them.
- Atomic unsaved-work recovery without automatic SQL execution.

## Installation and update

The candidate is an offline self-contained `win-x64` ZIP. It installs per user
under `%LOCALAPPDATA%\Programs\PostgreManagementStudio`; user state remains
under `%LOCALAPPDATA%\PostgreManagementStudio`. Normal uninstall removes
application binaries and the Start-menu shortcut while preserving user state.
See `docs/release/installation-guide.md`.

## Verified compatibility

- Windows 11 x64, standard-user per-user installation.
- PostgreSQL 18.4 local TCP with password authentication and client utilities.

## Important limitations

- This candidate is unsigned and intended for internal qualification only.
- PostgreSQL 14, remote TLS, and client-certificate qualification remain open.
- Editable data grids, dark theme, free docking, multi-window workflows, and
  several service-only workspaces are not part of the supported desktop surface.
- PostgreSQL utilities are discovered from a configured or existing local
  installation; no server or client utilities are bundled.
